# properties.txt -- the FFI properties, run by scripts/check-ffi.sh. The
# counterpart of the SPARK crate's spark/cryptol/properties.txt, in the same
# format.
#
# One line per property:
#
#     module file | property | function | mode | tests
#
# module file  Under verus/cryptol/, the module that states the property. It
#              declares the Verus exports as body-less foreign functions;
#              check-ffi.sh links the FFI library beside it.
# property     The property's name in that module.
# function     The Cryptol declaration the property checks, qualified by its
#              module as in the SPARK crate's scripts/board-rows.txt
#              (AES::GF28::xTimes).
# mode         exhaust (Cryptol's :exhaust) when the domain is at most 2^16
#              values, check (:check, random testing) otherwise.
# tests        For exhaust, the size of the domain: check-ffi.sh fails unless
#              Cryptol reports exactly that many tests. For check, the number
#              of random tests to run (Cryptol's tests setting).
#
# The properties are the SPARK crate's that check an executable function,
# with its names and test counts, and those of its spec properties whose
# function has an executable counterpart here. Only executable functions
# can be exported (doc/ffi.md); the SPARK crate's properties of its ghost
# spec alone have no line here:
#
#   prop_Dot, prop_Cipher128, prop_Cipher192, prop_Cipher256,
#   prop_InvCipher128, prop_InvCipher192, prop_InvCipher256,
#   prop_InvCipher'128, prop_InvCipher'192, prop_InvCipher'256,
#   prop_CipherExample, prop_KeyExpansion128, prop_KeyExpansion192,
#   prop_KeyExpansion256, prop_Example128KeyExpansion,
#   prop_Example192KeyExpansion, prop_Example256KeyExpansion,
#   prop_Encrypt128, prop_Encrypt192, prop_Encrypt256, prop_Decrypt128,
#   prop_Decrypt192, prop_Decrypt256, prop_AES128_Encrypt,
#   prop_AES128_Decrypt, prop_AES192_Encrypt, prop_AES192_Decrypt,
#   prop_AES256_Encrypt, prop_AES256_Decrypt, prop_AES128Example,
#   prop_AES192Example, prop_AES256Example, prop_FIPS197_C, prop_pad,
#   prop_parse, prop_step, prop_hash, prop_hash_bits, prop_hash_FIPS,
#   prop_Hash_Bytes, prop_Hash_Bytes_FIPS, prop_HMAC_texts, prop_HMAC_keys,
#   prop_HMAC_bits, prop_HMAC_RFC4231, prop_HMAC_init, prop_foldl,
#   prop_foldl_enumeration, prop_bit_8, prop_head_8, prop_bit_32,
